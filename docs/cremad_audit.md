# CREMA-D Adaptation Codebase Audit

This audit documents all hardcoded assumptions, modality-specific bindings, dimension constraints, and path dependencies across the codebase that block:
1. **6 emotion classes** (`anger`, `disgust`, `fear`, `happy`, `neutral`, `sad`) instead of MELD's 7 classes (`neutral`, `surprise`, `fear`, `sadness`, `joy`, `disgust`, `anger`).
2. **Audio + Video** modalities instead of Text + Video (including WavLM audio backbone, audio feature keys, and layer probing).
3. **Actor-based splitting and CREMA-D path isolation** (`cremad/` output namespace, `--media_root`).
